## How I work · 我的工作方式

| 01 · Frame | 02 · Design |
| --- | --- |
| Find the real problem beneath the feature request.<br/><sub>找到功能请求背后的真实问题。</sub> | Make complexity visible without making it overwhelming.<br/><sub>让复杂性可见，但不让它压倒用户。</sub> |
| **03 · Build** | **04 · Learn** |
| Prototype deeply enough that the product can be felt, not just explained.<br/><sub>把原型做深，让产品可以被体验，而不只被描述。</sub> | Put it in front of reality, then revise the judgment — not only the pixels.<br/><sub>让作品接触真实世界，再修正判断，而不只是像素。</sub> |
